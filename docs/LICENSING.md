# Licensing

## Project code

The zOS repository currently does not declare a project-wide license file. In the absence of an explicit license grant, do not assume that the repository's original zOS code is licensed for unrestricted redistribution.

Selecting a project license is an owner decision and should not be inferred from dependencies or third-party materials.

## Vendored RouterOS skills

Material under `skills/routeros-*` is derived from `tikoci/routeros-skills` and carries the upstream MIT terms described in `THIRD_PARTY_NOTICES.md`.

Those third-party MIT terms apply to that imported material; they do not automatically license unrelated original zOS code.

## Before a public release

Before advertising zOS as a redistributable open-source package, the repository owner should explicitly select a project license, add the corresponding license file, review third-party notices, and ensure package/release metadata agrees.
